# Agent guidance

Omi Local is a private audio memory system: Python/FastAPI backend, React/TypeScript web app, and SwiftUI iPhone companion.

## References

- For setup and repository layout, read [README.md](README.md).
- Before changing capture, archive, inference, or API behavior, read [architecture](docs/architecture.md); preserve capture timestamps, stable retry IDs, and source provenance.
- For configuration, deployment, backup/restore, and iOS builds, use the [operations guide](docs/README.md).
- Before changing BLE codecs or gestures, consult [device evidence and acceptance checks](docs/device-research.md); distinguish simulator results from physical-device verification.
- For web behavior and development, read [src/web/README.md](src/web/README.md).

## Working rules

- Keep inference local by default; hosted Omi transcript import is optional. Keep credentials on the backend.
- Use a temporary archive for tests and experiments. Preserve the user's `.env` and `data/`; run one backend process per archive.
- Edit web sources in `src/web/`; [scripts/build.sh](scripts/build.sh) generates and packages the served assets.
- Read commands and tooling settings from [pyproject.toml](pyproject.toml), [package.json](src/web/package.json), and [Package.swift](src/ios/Package.swift).

## Validation

Run checks for the changed component and report results or blockers:

- Backend: `uv run pytest` and `uv run ruff check .`.
- Web: `npm --prefix src/web test` and `npm --prefix src/web run build`.
- iOS core: `(cd src/ios && swift test)`; for app changes, also run the simulator build in the operations guide.
